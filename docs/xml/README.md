# Code Style

This directory contains the IntelliJ IDEA code style configuration (`allman.xml`) used by the code maintainer (Forwynn).
Please import and apply this scheme before submitting pull requests.

## How to Import in IntelliJ IDEA

1. Open **Settings** (`Ctrl+Alt+S` on Windows/Linux, `Cmd+,` on macOS).
2. Navigate to **Editor > Code Style**.
3. Click the gear icon next to **Scheme** and select **Import Scheme > IntelliJ IDEA code style XML**.
4. Select the XML file from this directory and click **OK**.
5. Reformat modified files (`Ctrl+Alt+L` / `Cmd+Option+L`) before committing.
